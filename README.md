The Neural Art Playground is a 100% frontend interactive art studio that lets users draw with AI assistance, apply real-time style transfers using TensorFlow.js, and collaborate via WebRTC. Built with React, Vite, and Tailwind CSS, it features a responsive canvas (Fabric.js/Three.js) with tools for brush customization, generative art effects, and artwork export as PNG/SVG with mock NFT metadata. The project requires no backend - all processing happens client-side using TensorFlow.js models for style transfer and PeerJS for P2P collaboration. To get started, clone the repo, run 'npm install' followed by 'npm run dev', then access the app at localhost:5173. Key dependencies include @tensorflow-models/image-stylization for AI features, GSAP for animations, and html-to-image for exports. The MIT-licensed project is designed for extensibility, with planned additions like Web Speech API voice controls and WebMIDI integration.
